# 报告格式规范

按照以下顺序输出 Markdown。只有在内容确实无关时才可以省略子章节，但必须保留 `数据范围与局限` 和 `来源清单`。

## 标题信息

- `# {品牌/商品}抖音投放研究报告`
- 研究目标
- 数据覆盖时间
- 报告生成时间

## 1. 执行摘要

给出三至五条重要结论。每条结论都要说明其对广告投放决策的意义。

## 2. 研究任务与数据范围

概括审核后的研究任务、采集成功的关键词、不可用关键词、RAG 证据范围和数据周期。

## 3. 行业与品类洞察

使用内部 RAG 证据说明宏观趋势、品类环境、消费者行为和适用的历史研究发现。

## 4. 品牌与竞品表现

仅在证据口径可比时，对目标品牌、品类词、商品词和竞品词进行比较。

## 5. 抖音人群洞察

覆盖地域、性别、年龄和兴趣。在数据可用时，同时解释人群占比和 TGI。

## 6. 关键词与内容机会

分析搜索关联词、上升词、品牌词歧义、商品或品类意图和可用内容主题。明显无关的关联词必须标记为噪声，不能推荐使用。

## 7. 投放策略建议

按照人群、内容、关键词、媒介或测试、效果衡量组织建议。建议必须被标记为建议，不能写成事实。

## 8. 数据范围与局限

列出不可用关键词、缺失模块、时间窗口差异、采集限制和仍需验证的结论。

## 9. 来源清单

在事实附近使用以下来源标记，并在本节给出去重后的完整来源列表：

- RAG: `[RAG-1] 《source》｜section｜Chunk n`
- Douyin: `[DY-1] 抖音指数｜keyword｜module｜period｜collected_at｜source_url`
- Web（如果提供）：`[WEB-1] 标题｜发布日期或访问日期｜URL`

插入图片时，使用调用方提供的绝对路径，并添加图注：

```markdown
![关键词“乐事”的人群分析截图](/absolute/path/to/audience_full.png)

图：抖音指数“乐事”人群分析，数据期为 YYYY-MM-DD 至 YYYY-MM-DD。
```
